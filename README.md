Apa yang dibuat adalah web game sederhana yaitu snake game, tujuannya sendiri adalah pemain mengarahkan ular(snake) ke makanannya yang akan muncul secara acak
bisa di posisi mana saja dengan cara menggerakan snakenya melalui swipe untuk mobile, dan pake arrow untuk Desktop, pemain lalu bisa melihat top skor dan riwayat skornya serta skor tertinggi
setelah itu pada layar leaderboard, pemain akan melihat yang mana saja skor paling tinggi ataupun riwayatnya, pemain juga bisa menghapus datanya, dan jika sudah selesai main
pemain bisa langsung balik ke menu dan klik exit
